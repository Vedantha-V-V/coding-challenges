# CCDISCORD
---

Discord Bot that can add coding challenges, give a random quote, list all coding challenges and also give a random quote

**Tech Stack & Tools:**
- python
- Disord Developer Portal

**Usage**
```bash
pip install -r requirements.txt
python bot.py
```

**Functionalities:**
- [x]  Greetings when entered Hi/Hello
- [x]  Give a random quote
- [x]  Give a random coding challenge
- [x]  List current coding challenges
- [x]  Add a new coding challenge
